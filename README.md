# Video Game Tournament Management System 🏆

## Overview
A Java-based application integrated with MySQL designed to organize, manage, and track esports competitions, player rosters, and tournament brackets. 

> 🥈 **Achievement:** Awarded 2nd Place in the Institute Software Development Competition.

## Key Features
* **Tournament Management:** Creation and scheduling of competition brackets and matches.
* **Participant Tracking:** Player and team registration linked to a relational database.
* **Object-Oriented Architecture:** Clean separation of concerns following robust OOP principles.
* **Data Persistence:** Relational database integration for real-time score updates and historical records.

## Tech Stack
* **Language:** Java
* **Database:** MySQL
* **Version Control:** Git & GitHub
* **Paradigms:** Object-Oriented Programming (OOP)
